# Ödev 2.4: Histogram Süre Kıyaslaması (1 Thread vs. 4 Thread)

Bu ödevde, tek thread ile doğrudan tüm görüntü üzerinde histogram hesaplama süresi ile görüntüyü 4 parçaya bölüp 4 thread kullanarak hesaplama süresi 20 tekrarlı deneyle kıyaslanmıştır.

## Çalıştırma
```bash
python3 main.py
```

## Üretilen Çıktılar
- `cikti/histogram_sure_cikti.txt`: Süre ölçüm ve kıyaslama tablosu.
